FAQ

Questions, answered

What is Xniper Social Studio?

A premium skill for Claude Code. You describe a post in plain language and it plans the slides, builds them in HTML and CSS, renders exact-size PNGs, and runs a release gate that refuses the generic template look. It also makes 15–30 second promo videos from one storyboard.

How much does it cost?

$29, one time. Every 1.x update is included, and there is no subscription.

How do I get it after I order?

Send the order form and we reply by email with payment options. Once the payment lands you receive a download link: the skill as a zip, a two-minute install guide and the licence.

Can I use it for client work?

Yes. The commercial licence covers your own work and paid work for your clients, and what you make with it is yours. One licence is one person, or one seat in a company.

What do I need to run it?

Claude Code and Python 3.9 or newer. The skill installs Pillow, Playwright with Chromium, edge-tts and a static ffmpeg build by itself the first time it needs them.

Which networks and sizes does it cover?

Instagram, Facebook, LinkedIn, X, Threads, TikTok, YouTube and Pinterest. Every post is rendered as a 4:5 master with a 9:16 and a 1:1 derived from it, and it builds platform canvases such as a 1280×720 thumbnail or a 1200×630 link image directly.

Can it make videos?

Yes. It turns a storyboard into a voiced, captioned MP4 per language and per size (9:16, 16:9 or 1:1) with music and sound effects, and a gate measures the rendered frames. A finished carousel can also become a reel in one command.

Can it post to Instagram for me?

It posts carousels, single images and reels through the Instagram API with Instagram Login, so no Facebook Page is needed, and it can pull reach, saves and shares back after 48 hours. Every command has a dry-run mode.
